 ОСНОВНЫЕ КОМАНДЫ
───────────────────────────────────────────────────────────────────────────────

Все в одном (Рекомендуется):
  ./fedora_full_setup.sh

Пошагово:
  ./run_lab5.sh help             # Справка
  ./run_lab5.sh setup            # Установка зависимостей
  ./run_lab5.sh build            # Сборка модулей
  sudo ./run_lab5.sh test-all    # Тестирование всех
  
Вручную:
  make check                     # Проверка окружения
  make                           # Сборка
  sudo insmod src/hello_module.ko
  dmesg | tail -20               # Посмотреть логи
  sudo rmmod hello_module




В Fedora VM откройте терминал и выполните:

    cd /path/to/lab5/gr1sub1/Chernookii_DI/
