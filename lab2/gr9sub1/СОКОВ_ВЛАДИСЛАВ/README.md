# Лабораторная работа №2: Продвинутые процессы Linux

Реализация супервизора процессов с поддержкой сигналов, Graceful Shutdown/Reload и управлением приоритетами.

## Структура проекта

```text
lab2/
  gr9sub1/
    СОКОВ_ВЛАДИСЛАВ/
      REPORT.MD         # Отчет с результатами экспериментов
      README.md         # Инструкция (этот файл)
      run.sh            # Скрипт для ручного запуска и демонстрации
      src/
        Makefile        # Сборочный файл
        supervisor.c    # Исходный код супервизора
        cpu_burn.c      # Исходный код воркера (нагрузка CPU)
        config.ini      # Конфигурационный файл
```

## Требования

  * Linux (или WSL2)
  * GCC, Make

## Сборка и Запуск

### 1. Ручной запуск

Используйте скрипт `run.sh` для интерактивной демонстрации:

```bash
chmod +x run.sh
./run.sh
```

Скрипт запустит супервизор в фоне и подскажет команды для отправки сигналов.

### 2. Компиляция вручную

```bash
cd src
make
# Запуск
./supervisor
```

## Управление (Сигналы)

Супервизор обрабатывает следующие сигналы:

  * `SIGTERM` / `SIGINT` — **Graceful Shutdown**: корректная остановка всех воркеров.
  * `SIGHUP` — **Graceful Reload**: перечитывание `config.ini` и перезапуск воркеров.
  * `SIGUSR1` — Переключить воркеров в **Light Mode** (малая нагрузка).
  * `SIGUSR2` — Переключить воркеров в **Heavy Mode** (высокая нагрузка).

## Конфигурация

Файл `src/config.ini` поддерживает настройки:

```ini
workers=2            ; Количество воркеров
heavy_work=9000      ; Время работы (мкс) в тяжелом режиме
heavy_sleep=1000     ; Время сна (мкс) в тяжелом режиме
light_work=2000      ; Время работы (мкс) в легком режиме
light_sleep=8000     ; Время сна (мкс) в легком режиме
```
