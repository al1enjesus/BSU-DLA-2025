# Практика: Keylogger — Перехват клавиатуры на уровне ядра

## Быстрый старт
```bash
# 1. Компиляция
make clean
make

# 2. Загрузка модуля
sudo insmod keylogger.ko

# 3. Проверка загрузки
dmesg | tail -10

# 4. Проверка /proc интерфейса
ls -la /proc/keylog
cat /proc/keylog

# 5. Тестирование перехвата клавиш
# Нажимайте клавиши в любом приложении
# Затем проверяйте:
cat /proc/keylog

# Для просмотра ввода в реальном времени 
watch -n 0.1 'echo "=== dmesg tail ===" && dmesg | tail -5 && echo "" && echo "=== /proc/keylog ===" && tail -10 /proc/keylog'

# 6. Тестирование переполнения буфера
# Быстро нажимайте много клавиш
# Проверяйте счетчик переполнений в выводе /proc/keylog

# 7. Проверка выгрузки
make uninstall
dmesg | tail -5
ls -la /proc/keylog  # Файл должен исчезнуть
```

##Выводы
Кольцевой буфер 2048 байт: 32 строки по 64 байта
Корректная очистка ресурсов:

kfree() для буфера
proc_remove() для /proc файла
input_unregister_handler() для отмены регистрации

Счетчик переполнений: отслеживает, сколько раз старые данные были удалены
Модуль компилируется без ошибок, загружается (insmod) и выгружается (rmmod) корректно, перехватывает нажатия клавиш, сохраняет клавиши в буфер,  можно прочитать лог через cat /proc/keylog, буфер не переполняется (кольцевой буфер), Корректная очистка ресурсов при выгрузке.
